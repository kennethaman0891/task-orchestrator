## 🎨 Creative Brief & Design System

* **Project:** Task Orchestrator (TO)
* **Official Tagline:** *"One Command. Multiple Agents. Complete Control."*
* **Core Value Proposition:** A native desktop command center that turns chaotic, disconnected AI agent CLI sessions (Claude Code, OpenCode, Codex, Gemini CLI) into an orchestrated, parallelized autonomous workspace.
* **Duration:** 30.0 seconds (720 frames @ 24fps)
* **Master Resolution:** 1920 × 1080 (1080p Full HD) / 16:9 master
* **Color Palette:**
  * **Obsidian Deep:** `#090A0C` (Matte dark mode background)
  * **Electric Cyan:** `#00D2FF` / `#38BDF8` (Active terminals, primary accent, velocity)
  * **Matrix Emerald:** `#22C55E` / `#10B981` (Task Orchestrator grid status, healthy agent telemetry)
  * **Neon Violet:** `#8B5CF6` / `#A855F7` (3D Developer City engine, workspace skyscrapers)
  * **Warning Crimson:** `#EF4444` (The Problem / unmanaged token thrashing & CLI chaos)
  * **Display Crisp White:** `#FFFFFF` (Headlines, tracking display typography)
* **Typography:**
  * Headline: Display Sans (SF Pro Display / Helvetica Bold / Arial Bold), tracking `-0.02em`, line-height `1.1`
  * Body & Tech Specs: Monospace (SF Mono / Menlo), uppercase letter-spacing `0.08em`
