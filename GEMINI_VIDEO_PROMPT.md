## Visual Style Guidelines

### Color Palette
- **Primary Background:** Deep dark (#0a0a0a or #111111)
- **Accent Colors:** 
  - Success green (#00ff88)
  - Warning amber (#ffaa00)
  - Error red (#ff4466)
  - Primary blue (#4488ff)
- **Terminal Background:** Near-black with slight blue tint
- **Text:** White (#ffffff) with gray secondary (#888888)

### Typography
- **Headings:** Clean sans-serif (Inter, SF Pro, or similar)
- **Code/Terminal:** Monospace (JetBrains Mono, Fira Code)
- **UI Text:** System font stack

### Animation Style
- Smooth, buttery transitions (300-500ms ease-out)
- Subtle glow effects on interactive elements
- Particle animations for wire connections
- Live pulse effects on status indicators
- Scale and fade for view transitions

## Key UI Elements to Highlight

1. **Header Bar:** Live clock, connection status dot, remote control button, view switcher
2. **Terminal Header:** Status dot (green/red), agent badge, model name, CWD, context menu
3. **Control Panel:** Terminal list with live stats, model picker dropdown, task queue
4. **Kanban Cards:** Task description, status badge, progress bar, context summary, accept/regenerate buttons
5. **IDE View:** Activity bar icons, file tree with icons, tabbed editor with minimap, breadcrumbs, status bar
6. **Floating Wires:** Colorful animated lines with flowing particles connecting terminals

8. **Token Dashboard:** Chart with per-model breakdown
