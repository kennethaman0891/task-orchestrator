## 💻 3. Ready-to-Run Grok CLI Shell Script

Save this script as `run_grok_video.sh` or run directly in your terminal:

```bash
#!/usr/bin/env bash
# ==============================================================================
# TTO Motion Graphics — Grok Video Generation CLI Runner
# ==============================================================================
set -euo pipefail

PROMPT="Cinematic 3D motion graphics promo for Task Orchestrator (TTO). 4K UHD, 60fps, Octane Render. Dark cyber tech aesthetic (#090A0C). 30+ chaotic terminals running Claude Code, opencode, and Codex snap into a pristine 36-pane dynamic aspect-ratio grid with a floating translucent notch. Glowing fiber-optic neural cables connect terminal nodes. Holographic Kanban task decomposition, isometric 3D cyber city with skyscrapers and autonomous agent cars, and Jarvis voice AI. Climax: 3D rounded-square matte obsidian badge with brushed platinum 'T' and illuminated cyan-to-violet neon ring 'O' with blinking prompt '> _' surrounded by electric blue plasma arcs. Typography reveal: 'TASK ORCHESTRATOR — One Command. Multiple Agents. Complete Control.'"

echo "=========================================================="
echo "🎬 Launching Grok Video Generation for Task Orchestrator"
echo "=========================================================="

# If using grok CLI binary:
if command -v grok &> /dev/null; then
  echo "Found grok CLI. Generating video..."
  grok video \
    --prompt "$PROMPT" \
    --duration 10 \
    --aspect-ratio "16:9" \
    --resolution "1080p" \
    --output "frontend/public/videos/login.mp4"
else
  echo "grok CLI binary not found in PATH."
  echo "Displaying formatted prompt to copy & paste into your Grok prompt CLI:"
  echo ""
  echo "----------------------------------------------------------"
  echo "$PROMPT"
  echo "----------------------------------------------------------"
fi
```
